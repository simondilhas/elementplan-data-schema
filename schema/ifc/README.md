# IFC LinkML Modules

This folder contains generated, versioned IFC vocabulary modules used by the
Elementplan schema and editor validation.

## Files

- `ifc_common.linkml.yaml`
  - shared IFC datatypes (`IFCDatatypeEnum`)
- `ifc2x3.linkml.yaml`
  - `IFC2X3EntityEnum` (all IFC2X3 entities)
- `ifc4.linkml.yaml`
  - `IFC4EntityEnum` (all IFC4 entities)
- `ifc4x3.linkml.yaml`
  - `IFC4X3EntityEnum` (all IFC4X3_ADD2 entities)
- `psets_ifc2x3.linkml.yaml`
  - IFC2X3 PSet/Qto template vocabulary + reusable catalog classes
- `psets_ifc4.linkml.yaml`
  - IFC4 PSet/Qto template vocabulary + reusable catalog classes
- `psets_ifc4x3.linkml.yaml`
  - IFC4X3 PSet/Qto template vocabulary + reusable catalog classes

These files are generated by:

```bash
python scripts/generate_ifc_linkml.py
```

## Frontend Artifacts

The same generator emits frontend artifacts in:

- `api/elementplan_editor/static/generated/ifc2x3.json`
- `api/elementplan_editor/static/generated/ifc4.json`
- `api/elementplan_editor/static/generated/ifc4x3.json`
- `api/elementplan_editor/static/generated/psets_ifc2x3.json`
- `api/elementplan_editor/static/generated/psets_ifc4.json`
- `api/elementplan_editor/static/generated/psets_ifc4x3.json`

Backend and frontend both consume generated artifacts from this pipeline.

The generated `psets_*.linkml.yaml` modules are intended for schema exchange and
cross-project reuse. They provide:

- an enum of valid PSet/Qto template names per IFC version
- classes for a portable catalog shape (`...PsetCatalog`, `...PsetTemplate`, `...EntityPsetAssignment`)
- typed links to the corresponding IFC entity enum module (`ifc2x3/ifc4/ifc4x3`)

## CI Guard

CI verifies generated artifacts are up to date via:

```bash
python scripts/generate_ifc_linkml.py --check
```

## Publishing Convention

When publishing externally, version by IFC release and module revision, e.g.:

- `https://ifc.linkml.dev/ifc2x3/v1`
- `https://ifc.linkml.dev/ifc4/v1`
- `https://ifc.linkml.dev/ifc4x3/v1`

Keep changelogs for additions/removals between module versions.
